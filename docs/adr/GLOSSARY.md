# Iteration-2 Glossary

Terms used across the Iter-2 work packages. Kept terse; each entry links to the
canonical paper where relevant.

| Term | Definition | Source |
|---|---|---|
| **Walk-Forward Validation (WF)** | Time-ordered CV where the validation set always follows the training set in time. Single backtest path, realistic but limited robustness. | paper #12 |
| **Combinatorial Purged CV (CPCV)** | Splits data into N ordered groups, chooses k for testing across all combinations, purges overlapping train/test samples and applies an embargo gap. Generates multiple backtest paths. | paper #12, §2.4.4 |
| **Purge** | Removing training samples whose label window overlaps the test set, preventing leakage. | paper #12 |
| **Embargo** | An additional gap after each test set to avoid autocorrelation leakage between train and test. | paper #12 |
| **Probability of Backtest Overfitting (PBO)** | Probability that a strategy optimal in-sample underperforms out-of-sample. Computed via Combinatorially Symmetric CV (CSCV). | paper #12, §2.5.1 |
| **CSCV** | Splits the performance matrix into S submatrices, forms in-sample/out-of-sample combos, ranks configs, integrates the logit rank distribution to get PBO. | Bailey et al. 2016 |
| **Deflated Sharpe Ratio (DSR)** | Sharpe adjusted for the number of independent trials (multiple-testing guard). Uses expected max Sharpe under the trial count. | paper #12, §2.5.2 |
| **Probabilistic Sharpe Ratio (PSR)** | Probability the true Sharpe exceeds a benchmark, adjusted for skew/kurtosis. DSR sets that benchmark from the trial count. | Bailey & López de Prado 2012 |
| **Matthews Correlation Coefficient (MCC)** | Single-number classification quality metric, robust to imbalance; used to evaluate the RF regime predictor per class. | paper #11 |
| **KMRF** | KAMA+MSR+Random Forest regime predictor; RF predicts the regime labels ex-ante. | paper #11 |
| **Regime prediction vs detection** | Detection (HMM) labels after onset; prediction (RF) labels next-day ex-ante from features up to t. | paper #11 |
| **Variational Autoencoder (VAE)** | Probabilistic autoencoder; latent is a distribution (μ, σ²), sampled via reparameterization. Used for Monte-Carlo stress scenario generation. | paper #7 |
| **Stress scenario** | Synthetic extreme market return vector generated by perturbing/sampling the latent space. | paper #7 |
| **GARCH(1,1)** | Conditional volatility model: σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}; 1- and 5-day vol forecasts. | D10 |
| **Combinatorial Purged leak test** | Unit test asserting every train/test pair is separated by ≥ embargo_bars. Non-negotiable per plan §14.4. | D-3 |
